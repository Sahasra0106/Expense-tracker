# 💰 Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript to manage income, expenses, and balance in one place.

## ✨ Features

- 💵 **Total Balance:** View the remaining balance.
- 📈 **Total Income:** Track your total income.
- 💸 **Total Expenses:** Calculate total expenses.
- ➕ **Add Transactions:** Add income or expense transactions with a description and amount.
- 🗑️ **Delete Transactions:** Remove transactions whenever needed.
- 💾 **Local Storage:** Automatically save transactions in the browser, even after refreshing the page.
- 📱 **Responsive Design:** Use the application on desktop and mobile screens.

## 🛠️ Technologies Used

- **HTML5** – Structures the web page.
- **CSS3** – Styles the interface and makes it responsive.
- **JavaScript** – Handles transaction management and calculations.
- **Local Storage** – Stores transaction data in the browser.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Add income and expense transactions to see the balance update automatically.
